# Amazon ML Challenge 2026 – Evaluation Portfolio

## Overview
A portfolio presentation of my evaluation and validation contribution to a team project focused on business entity resolution.

Business entity resolution involves identifying records that refer to the same real-world business across different data sources, despite inconsistent or incomplete information.

## My Contribution
My focus was the evaluation and packaging workstream.

The portfolio covers:
- Evaluation validation workflows
- F0.5 scoring
- Threshold analysis and optimisation
- Prediction output validation
- Ground-truth evaluation utilities

## Technical Stack
- Python
- Machine Learning evaluation
- Data validation
- Classification metrics
- Experimental analysis

## Repository Structure
- `evaluation/` – approved evaluation scripts
- `documentation/` – methodology and workflow notes
- `results/` – approved, non-sensitive evaluation summaries

## Project Context
Developed as part of a team participating in the Amazon ML Challenge 2026.

This repository is a separate portfolio presentation of approved individual contributions. It does not contain competition datasets or private submission artifacts.

## Note
This repository is intended to demonstrate my individual technical contribution. It does not claim ownership of the entire team project or guarantee any particular competition outcome.
